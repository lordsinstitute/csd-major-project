# 🏡 PropLens AI - Smart Real Estate Pricing Engine & Neighborhood Analyzer

A complete, production-grade prototype for geospatial real estate valuation and automated 1km neighborhood micro-market analytics. **PropLens AI** unifies interactive spatial mapping with machine learning regression and transparent price factor decomposition.

---

## 🌟 The 3 Core Functional Pillars

### 📍 Pillar 1: Geospatial Map Scanner (1 km Radius Check)
* **Interactive Leaflet.js Map**: Click any parcel on OpenStreetMap or drag the custom property pin to capture precise GPS coordinates (Latitude & Longitude).
* **1,000m Geodesic Perimeter**: Automatically projects a geodesic 1 km radius boundary around the selected property.
* **Neighborhood Amenity Detection**: Scans and categorizes nearby urban infrastructure within 1km:
  * 🚇 **Transit Hubs & Metro Stations** (Blue markers)
  * 🏫 **Premier Schools & Academies** (Amber markers)
  * 🏥 **Multispecialty Hospitals & Urgent Care** (Rose markers)
  * 🌳 **Urban Parks, Lakes & Green Spaces** (Emerald markers)
  * 🛍️ **Commercial Centers & Supermarkets** (Purple markers)
* **Livability Index**: Computes an algorithmic 0–100 neighborhood livability score based on proximity and density.

### 🧠 Pillar 2: Smart Pricing Estimator (ML Regression)
* **High-Accuracy ML Model**: Trained Scikit-Learn **Gradient Boosting Regressor** achieving **R² > 0.98** benchmark accuracy on diverse property listings.
* **Multi-Dimensional Inputs**:
  * Physical dimensions: Living area (sq.ft.), bedroom count (BHK), bathroom count, property age (depreciation).
  * Architecture type: Apartment, Independent House, Villa.
  * Spatial attributes: Latitude, longitude, 1km transit density, school counts, healthcare access, and distance to nearest metro.
* **Market Valuation Output**: Generates fair market valuation, 95% statistical confidence range, and unit price per sq.ft.

### 📊 Pillar 3: Price Breakdown & Explainability Engine
* **Transparent Factor Decomposition**: Breaks down exactly how the predicted price was calculated:
  * 📐 **Living Area Contribution**: Core baseline construction & space value.
  * 🛏️ **Room Configuration Impact**: Value added by bedrooms and bathrooms.
  * 🌳 **1km Neighborhood Amenities**: Value premium generated by walking-distance transit, premier schools, and parks.
  * ✨ **Architecture / Type Premium**: Luxury villa & independent land multipliers.
  * ⏳ **Age Depreciation**: Negative market adjustment for wear and structure aging.
* **Visual Progress Meters**: Interactive contribution bars and micro-location tags directly in the split-screen sidebar.

### 🗄️ Database Logging (SQLite `proplens.db`)
* Every property query, geospatial coordinate pair, amenity count, and ML estimate is automatically logged into an embedded SQLite database (`backend/proplens.db`).
* Includes REST history retrieval (`/api/history`) and log purging (`/api/history/clear`).

## 🛠️ Technology Stack & Architecture

| Layer | Technologies Used |
|---|---|
| **Frontend UI** | HTML5, CSS3 (Modern Dark Glassmorphism), Vanilla ES6+ JavaScript |
| **Mapping Engine** | [Leaflet.js](https://leafletjs.com/) v1.9.4 & [OpenStreetMap](https://www.openstreetmap.org/) tile layers |
| **Backend API** | Python, [Flask](https://flask.palletsprojects.com/) v3.0+, Flask-CORS |
| **Machine Learning** | [scikit-learn](https://scikit-learn.org/) (GradientBoostingRegressor), NumPy, Pandas, Joblib |
| **Database** | SQLite 3 (`backend/proplens.db`) file-based persistent storage |

## 🚀 Step-by-Step Setup & Execution Instructions

### Prerequisites
* **Python 3.8+** installed on your system.
* Standard web browser (Chrome, Edge, Firefox, Safari).

---

### Step 1: Install Dependencies
Open your command prompt or terminal in the project root directory (`c:\Users\Hp\Downloads\Proplens`):

```bash
pip install -r requirements.txt
```

*This installs Flask, Flask-CORS, scikit-learn, pandas, numpy, and joblib.*

---

### Step 2: Train the Baseline Machine Learning Model
Train the regression model on the synthetic real estate and neighborhood dataset:

```bash
python backend/train_model.py
```

**Expected Output:**
```text
=================================================================
 PropLens AI - Training Smart Real Estate Pricing Engine 
=================================================================
[1/4] Generating 2,500 synthetic property listings with geospatial features...
[2/4] Splitting train (80%) and test (20%) datasets...
[3/4] Fitting Scikit-Learn Gradient Boosting Regressor...
-----------------------------------------------------------------
 Model Evaluation Metrics:
  * Training R^2 Score : 0.9986
  * Testing R^2 Score  : 0.9879 (Accuracy Benchmark)
  * Mean Absolute Error: $33,742.17
  * Root Mean Sq Error : $49,772.11
-----------------------------------------------------------------
[4/4] Saving model artifact to: backend/model.pkl
SUCCESS: Model successfully trained and saved as 'model.pkl'.
```

---

### Step 3: Run the Flask Backend Server
Start the Flask application server:

```bash
python backend/app.py
```

The server initializes SQLite (`proplens.db`), loads `model.pkl`, and binds to:
```text
http://127.0.0.1:5000
```

---

### Step 4: Open the Frontend Interface
You can access PropLens AI in either of two ways:

1. **Directly via Flask Server (Recommended):**
   Open your browser and navigate to:
   ```text
   http://127.0.0.1:5000/
   ```

2. **Standalone Browser File:**
   Open `frontend/index.html` directly in your browser. Since Flask-CORS is enabled on all `/api/*` routes, the standalone frontend communicates seamlessly with `http://127.0.0.1:5000`.

## 📡 REST API Specification

### 1. Health & Status
* **Endpoint:** `GET /api/health`
* **Response:**
```json
{
  "status": "healthy",
  "service": "PropLens AI Engine",
  "version": "1.0.0",
  "model_loaded": true,
  "model_metrics": { "r2_score": 0.9879, "mae": 33742.17 },
  "database": "SQLite connected (proplens.db)"
}
```

---

### 2. Map Scanner: 1km Radius Amenities (Pillar 1)
* **Endpoint:** `POST /api/scan-amenities` (or `GET /api/scan-amenities?lat=...&lng=...`)
* **Request Payload:**
```json
{
  "latitude": 12.9716,
  "longitude": 77.5946
}
```
* **Response:** Returns all amenities detected within 1,000 meters, distances, category counts, and neighborhood livability score.

---

## 💡 Engineering Highlights
* **Ponytail Discipline**: Minimal dependencies, pure stdlib SQLite integration, native mathematical decomposition, and direct Leaflet.js rendering without heavyweight frontend frameworks.
* **Geodesic Accuracy**: Real Haversine spherical distance calculations ensure pinpoint 1 km amenity perimeter detection.
* **Responsive Split Screen**: Left control/results drawer with smooth scroll; full-height right Leaflet pane that gracefully stacks vertically on mobile screens.
* **Vercel Serverless Ready**: Automated `/api/index.py` WSGI bridge, edge static caching, and `/tmp` SQLite fallback compatibility.


1. **Commit and Push to GitHub:**
   ```powershell
   git branch -M main
   git add .
   git commit -m "Deploy PropLens AI: Flask + Leaflet.js + Scikit-Learn on Vercel"
   git remote add origin https://github.com/<your-username>/proplens-ai.git
   git push -u origin main
   ```

2. **Deploy via Vercel CLI:**
   ```powershell
   # Install CLI (if not already installed)
   npm install -g vercel

   # Deploy directly to production (use vercel.cmd or npx vercel on Windows PowerShell)
   vercel.cmd --prod
   ```

3. **Expected Live Production URL:**
