# Online Graphical Password Authentication System

## Project Description

The Online Graphical Password Authentication System is a web-based authentication system that allows users to register and log in using graphical password techniques.

The project provides user registration, graphical password authentication, login functionality, password recovery, and a user screen through a web-based interface.

## Features

- User Registration
- Graphical Password Authentication
- User Login
- Forgot Password / Password Recovery
- User Screen
- Image-based Password Selection
- Database Connectivity
- Web-based User Interface

## Technologies Used

- Java / JSP
- HTML
- CSS
- Python
- MySQL
- Apache Tomcat

## How to Run

1. Install and configure Java and Apache Tomcat.
2. Install and configure MySQL.
3. Set up the project database using the provided database file.
4. Place the project files in the appropriate Tomcat web application directory.
5. Start the MySQL server.
6. Start the Apache Tomcat server.
7. Open the application in a web browser.
8. Register a user and test the graphical password authentication system.

## Main Modules

### Registration

Allows new users to create an account and configure their graphical password.

### Login

Authenticates registered users using their graphical password.

### Forgot Password

Provides password recovery functionality.

### User Screen

Displays the authenticated user's interface after successful login.
